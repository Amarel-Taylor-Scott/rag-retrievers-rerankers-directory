# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-06-22

### Added
- Curated directory of 13 RAG retrieval & reranking tools across 5 categories
  (sparse/lexical retrieval, late-interaction retrieval, reranker libraries,
  reranker models, and managed reranker APIs), with open-source/license metadata.
- `retriever-dir` CLI: list (filters: category/open-source/proprietary), search,
  categories, stats, export (json/csv), generate.
- Auto-generated README, registry-integrity tests, and CI (incl. README-in-sync check).
